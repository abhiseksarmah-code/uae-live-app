# Live in the Emirates

Android app listing upcoming concerts and stand-up comedy in Dubai, Abu Dhabi and Sharjah.

- **Download:** the latest APK is on the [Releases page](../../releases/latest) (`LiveInTheEmirates.apk`).
- **Data:** `data/events.json`, refreshed every morning. The app downloads it on open and keeps an offline copy.
- **Build:** GitHub Actions builds and signs the APK on every push to `main` (`.github/workflows/build-apk.yml`).

Installing: open the APK on your phone and allow "Install unknown apps" for your browser or file manager when Android asks.
